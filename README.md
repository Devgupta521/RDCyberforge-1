# RD CyberForge Website

A responsive, single-page website built with plain HTML, CSS, and JavaScript. No framework or package installation is required.

## Files
- `index.html` — page structure and content
- `style.css` — styling, layout, colours, and responsive design
- `script.js` — mobile navigation, current year, and community-link setup
- `assets/rd-cyberforge-logo.jpeg` — supplied RD CyberForge logo
- `assets/cyber-background.jpeg` — supplied cybersecurity background image

## Run it in VS Code
1. Extract the ZIP file.
2. Open the `rd_cyberforge_website` folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension and select **Open with Live Server**.
4. Keep the `assets` folder beside the three code files so the images load correctly.

## Before publishing
1. Open `script.js` and replace the empty `COMMUNITY_URL` value with your official registration form or community link.
2. Check the email and all content in `index.html`.
3. Test the mobile menu and links.
4. Publish the folder using your preferred static website host (for example, GitHub Pages, Netlify, or Vercel).

The Google Fonts import requires an internet connection; the page remains usable if the font service is unavailable.
